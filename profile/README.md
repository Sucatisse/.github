# Sucatisse

**Preserving automotive history, one bolt at a time.**

Sucatisse is a classic-car restoration club. We rebuild, document, and share the cars we love — and the tooling we wished existed while doing it.

## Open-source tools

We build small, focused tools to make restoration work less painful — and publish them so other enthusiasts and clubs can use them too.

| Tool | What it does | Live |
| --- | --- | --- |
| **Interactive Manual** | The rendering engine behind every manual: search, deep-linking, figure galleries, all static and fast. | [manuals.sucatisse.com](https://manuals.sucatisse.com/) |
| **Human Touch** | Browser app for annotating workshop-manual PDFs — page labels, image regions — into a clean structured sidecar. | [ht-pdf.sucatisse.com](https://ht-pdf.sucatisse.com) |
| **Pilot Tag Generator** | Design and export print-ready name tags (flag + name) for racing pilots. Fully client-side. | [pilot-tag.sucatisse.com](https://pilot-tag.sucatisse.com) |
| **Keychain Generator** | Design and export custom club keychains, ready for production. | [keychains.sucatisse.com](https://keychains.sucatisse.com) |
| **Fitment Calculator** | Wheel and tire fitment: compare a current and a proposed setup for poke, tuck, clearance, speedo error and brake fit. | [fit.sucatisse.com](https://fit.sucatisse.com) |
| **Spring Rate Calculator** | Spring rates from corner weights and ride frequency, plus a decoder for unlabeled springs. | [springs.sucatisse.com](https://springs.sucatisse.com) |

## Stack

Static-first, framework-light, deployed on Cloudflare: each manual (and the hub in front of them) runs as a Cloudflare Worker with static assets. TypeScript, Vite, Next.js, Tailwind CSS v4. No tracking, no fluff.
